### Converting javascript script into human legible format
This repository contains my submission for the first task on the wikimedia project addressing the lusophone technology wishlists proposals.

##  What the Code Does
1. Reads article data from the csv file.
2. Iterates over each article entry.
3. Formats each entry into the following sentence:
   > Article "ARTICLE TITLE" (Page ID PAGEID) was created at MONTH DAY, YEAR.
4. Injects the formatted output into the HTML element with the `#results` ID.

## Tools used
- HTML
- Javascript
